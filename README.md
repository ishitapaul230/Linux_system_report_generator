# Linux_system_report_generator
A bash script to generate a Linux system report

# About the Project
This is my first Linux project.It is written using bash scripting and helps collect basic system information in one text file.

# Features
Displays the hostname 
Shown the Linux kernel version
Displays disk usage
Shows memory usage
Lists the top 5 running processes

# Technologics Used
Kali Linux
Bash scripting
Visual Studio Code
Git and Github

# How to Run 
1. Open the terminal in the project folder.
2. Run the following command: bash system_report.sh
3. The system information will be saved in system_report.txt.
